# ToDo List App

A simple to‑do list application built with **React + Vite**.

## Features

- Add tasks
- Mark tasks as done
- Remove tasks
- Fast dev workflow with Vite

## Tech stack

- React
- Vite

## Getting started

### Install

```bash
npm install
```

### Run locally

```bash
npm run dev
```

### Build

```bash
npm run build
npm run preview
```

## Roadmap

- Persist tasks with localStorage
- Add filters (All / Active / Completed)
- Add due dates and priority
